# Currency Converter

Приложение с графическим интерфейсом на базе библиотеки Tkinter для конвертации валют по актуальному курсу. Проект поддерживает сохранение истории операций.

## Автор
Гусев Кирилл

## Функционал
- Выбор валют из выпадающего списка (USD, EUR, RUB, и т.д.).
- Проверка корректности ввода (сумма должна быть строго положительным числом).
- Использование внешнего API для получения точных котировок.
- Автоматическое сохранение истории конвертаций в файл `history.json` с возможностью загрузки при следующем запуске.

## Как получить API-ключ
Для работы приложения требуется ключ от сервиса ExchangeRate-API:
1. Перейдите на сайт [exchangerate-api.com](https://www.exchangerate-api.com/).
2. Нажмите кнопку «Get Free Key».
3. Зарегистрируйтесь, указав свой email.
4. Скопируйте полученный API Key из личного кабинета.
5. Откройте файл `main.py` и вставьте ваш ключ в переменную `API_KEY = "YOUR_API_KEY"`.

## Примеры использования (Тесты)

**Тест 1: Успешная конвертация**
- Действие: Ввести `100`, выбрать Из: `USD`, В: `EUR`, нажать «Конвертировать».
- Ожидаемый результат: Появится надпись с рассчитанной суммой, запись будет добавлена в таблицу истории.

**Тест 2: Проверка на отрицательное число**
- Действие: Ввести `-50` и нажать «Конвертировать».
- Ожидаемый результат: Появление всплывающего окна с ошибкой "Пожалуйста, введите корректное положительное число".

**Тест 3: Проверка на ввод букв вместо цифр**
- Действие: Ввести `abc` и нажать «Конвертировать».
- Ожидаемый результат: Всплывающее окно с ошибкой валидации ввода.
